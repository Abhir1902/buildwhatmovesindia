# SETU

Compliance operating system for Indian businesses.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/overview`.

No environment variables. No login.

## Deploy on Vercel

1. Import this repository in Vercel.
2. Framework preset: Next.js.
3. Deploy.

Agent walkthrough: `/demo` and `/llms.txt`.
